# CNPJ360 — projeto acadêmico

## Requisitos
- Node.js 18+
- npm

## Instalação
```bash
npm install
npm start
```

Abra:
- http://localhost:3000
- http://localhost:3000/admin.html

## Acesso administrativo da demonstração
Usuário: `admin`
Senha: `admin123`

Troque a senha antes de qualquer uso real usando variáveis de ambiente.

## Excel
A primeira aba da planilha é importada.

Colunas aceitas:
- CNPJ
- Nome / Razão Social / Nome Fantasia
- CPF
- Telefone
- Email / E-mail
- Cidade / Município
- Status / Situação
- Competência
- Valor
- Vencimento
- Situação

O sistema usa SQLite local para a demonstração.

## Observação
O pagamento PIX deste projeto é apenas uma simulação acadêmica. Não há cobrança real, integração bancária ou processamento financeiro.
